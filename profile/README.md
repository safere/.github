# SafeRE

**Safe, correct, and fast regular expressions for Java.**

SafeRE provides linear-time regular expression matching with familiar
`Pattern` and `Matcher` APIs. It targets `java.util.regex` compatibility
within that guarantee, with Unicode support and direct UTF-8 matching.

- [Get started](https://github.com/safere/safere#installation)
- [Documentation](https://github.com/safere/safere/tree/main/docs)
- [Performance results](https://github.com/safere/safere/blob/main/BENCHMARKS.md)
- [Questions, bugs, and feature requests](https://github.com/safere/safere/issues)

SafeRE began as a Java port of RE2 and incorporates code from RE2/J.
